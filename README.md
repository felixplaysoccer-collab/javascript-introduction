# JavaScript Introduction Assignment

An introductory JavaScript project for INFOST 320 – Web Design II.

## Features

- Prompts visitors to enter their name
- Displays JavaScript variables and an object in the browser's developer console
- Uses checkboxes to change the page's background and text colors
- Demonstrates DOM event handlers and JavaScript basics

## Live demo

https://courageous-lily-e621d8.netlify.app/

## Technologies

HTML, CSS, JavaScript

## How to run

Open `index.html` in a web browser, enter a name in the prompt, and try both color checkboxes. Open the browser's developer console to inspect logged values.
